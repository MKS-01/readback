## Features

  • ▮ 100% offline

    Extraction, summarization, and speech all run on-device — MLX on Apple Silicon. No accounts, nothing phoning home.

  • ▮ A voice worth listening to

    CSM-1B neural TTS (Sesame). Two built-in reading voices, clone any voice from a short clip, or LoRA fine-tune for more fidelity.

  • ▮ Full or Summary mode

    Hear the article verbatim, or let a local LLM (Ollama) rewrite it as a spoken explanation first. Switch models from the CLI with a RAM-fit check.

  • ▮ A real terminal player

    Pause, seek ±5 s, and a transcript that highlights word by word in sync with the voice — all in Ink, all in your shell.

## How it works

## Quick start

macOS on Apple Silicon · Python 3.10–3.12 · Bun · Ollama (Summary mode only)

# 1. Ollama for Summary mode (skip for Full mode)
ollama pull gemma4:26b

# 2. Install the server
git clone https://github.com/MKS-01/readback.git && cd readback
python3.11 -m venv .venv && source .venv/bin/activate
pip install -e .

# 3. Build the terminal client → ~/.local/bin
cd src/cli && ./install.sh && cd ..

# 4. Read something
readback-cli

Paste a URL, watch it synthesize, audio plays in your shell. Full docs in the README.

## The story

I read a lot, but there's a whole pile of good writing I never get to — some days I'd just rather listen than read another wall of text. I've been tinkering with voice agents since college (2015), back when it was a speech-to-text → text-to-speech loop held together with duct tape.

readback actually started as a real-time voice assistant — mic capture, wake-words, the whole live cascade. Building that taught me the part I really wanted wasn't the conversation; it was the listening. So I cut everything else, and the assistant became a reader: a local LLM for summaries, a neural voice (CSM-1B) for the reading, all on-device, nothing phoning home. It lives in the terminal, where it always felt most at home.

Made to make reading interesting again.

## Stack

  • Extractiontrafilatura — URL → clean article text
  • SummaryOllama — local LLM, gemma4:26b default (Summary mode only)
  • VoiceCSM-1B (Sesame) via csm-mlx — MLX / Metal, 24 kHz
  • ServerFastAPI + WebSocket — streams progress, serves the WAV
  • ClientBun + TypeScript + Ink — the terminal UI
  • Playbackafplay — pause, seek, word-synced transcript (macOS)
